# وب‌سایت دلگشا

## اجرا
فایل `index.html` را در مرورگر باز کنید. برای ویرایش کد می‌توانید کل پوشه را در GitHub بارگذاری کنید.

## فایل‌ها
- `index.html`: ساختار و محتوای صفحه
- `style.css`: رنگ‌ها، قالب و طراحی واکنش‌گرا
- `script.js`: منوی موبایل، تاریخ و رفتار نمایشی فرم

## شخصی‌سازی ضروری پیش از انتشار
1. نام، لوگو، اطلاعات تماس و متن‌های نمونه را با اطلاعات واقعی جایگزین کنید.
2. سه منوی آبشاری داخل بخش `quick-menu` با تگ‌های `<details>` ساخته شده‌اند؛ برای افزودن گزینه، یک `<a>` جدید داخل `.dropdown-content` اضافه کنید.
3. برای ویدیوی مدیرعامل، آدرس فایل MP4 را در `<source src="">` قرار دهید. در صورت استفاده از سرویس میزبانی ویدیو، می‌توانید تگ `video` را با iframe مناسب جایگزین کنید.
4. تصاویر این قالب از Unsplash بارگذاری می‌شوند و برای نمایش نیاز به اینترنت دارند؛ در نسخه نهایی بهتر است تصاویر مجاز خودتان را در مخزن قرار دهید.
5. فرم تماس فعلاً نمایشی است و پیام را ارسال نمی‌کند. برای ارسال واقعی، آن را به بک‌اند یا سرویس فرم متصل کنید.
6. این قالب یک طراحی مستقل و الهام‌گرفته از تصویر مرجع است؛ متن‌ها و ساختار آن بازنویسی نمونه‌اند و ادعای بازنشر دقیق محتوای رسمی mimt.gov.ir را ندارند. پیش از انتشار، اطلاعات رسمی را با منبع اصلی تطبیق دهید.

## انتشار در GitHub Pages
محتویات این پوشه را در ریشه یک repository قرار دهید. سپس از Settings → Pages، شاخه اصلی و پوشه ریشه (`/(root)`) را انتخاب کنید.
